# Lang Systems Licence Register portfolio card

Reusable public portfolio presentation for the fictional browser demo. Display name: **Lang Systems Licence Register**; compact card name: **Licence Register**.

Paste `licence-register-card.html` into the website portfolio rail and append `licence-register-card.css` after its shared card styles. Both excerpts match the implementation in the Lang Systems website. The stylesheet scopes every rule to `.licence-register-product`; the card uses no scripts, remote fonts, images or product data requests. Outside the existing website, give its parent an appropriate width (340–560px works well); the anchor fills its parent and retains an explicit keyboard focus ring.

The entire card links to [the public fictional demo](https://langzonedev.github.io/LicenceManager-Web/). Its miniature interface is decorative and hidden from assistive technology. All preview records and quantities are fictional; keys are masked decorative dots. “Portfolio demo” describes the available experience without claiming production readiness, real authentication or persistent storage. The separate Lang Systems company logo remains unchanged.

Company palette verified against [the live website](https://langsystems.com.au/) on 20 October 2026. This bundle contains presentation only; no customer records, keys, private backend source or deployment configuration.
